# Furniture House — Relational Database

## Project Overview

A relational database developed as part of university coursework for a fictional furniture rental company using Oracle SQL.

## Technologies Used

- Oracle SQL
- Relational database design
- SQL constraints and data types

## Database Structure

The database includes tables for managing different areas of the furniture business, including:

- Branch information
- Customer or member records
- Furniture items
- Staff and stock records
- Rental-related information

## Database Features

- Primary keys for identifying individual records
- Data types including VARCHAR2, NUMBER and DATE
- NOT NULL and CHECK constraints for data integrity
- SQL statements for creating and managing database tables

## Project Purpose

This project provided practical experience in designing a relational database, organising business information into structured tables and applying SQL concepts to support data management.

## Important Note

The SQL script contains DROP TABLE statements and should only be executed in a dedicated test or coursework database environment.
